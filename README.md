# 📊 Responsive Admin Dashboard

- A Responsive financial management dashboard built with Flutter, designed to help administrators and users track expenses, manage wallets, and monitor investments in real time.

---

## 🤳 App Screens

### Core Functionality

- **Dashboard** – Displays balance, income, and expenses with real-time statistics.
- **Transactions** – Track all financial activities with detailed history.
- **Wallet Account** – Manage cards and view account details securely.
- **Quick Invoice** – Generate and send invoices instantly.
- **Investments** – Monitor investment performance with analytics and charts.
